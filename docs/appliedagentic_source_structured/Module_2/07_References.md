# Key Takeaways

A comprehensive glossary covering all key terms from this module is available as a downloadable PDF alongside the original course materials. Key terms include:

- **Agentic AI** — AI systems capable of autonomous, goal-directed action
- **Multi-Agent System (MAS)** — a network of AI agents working together
- **Open source** — software with publicly available, modifiable code
- **Vibe coding** — software creation through natural language AI prompts
- **RAG (Retrieval-Augmented Generation)** — AI that pulls external data to improve responses
- **Utility function** — a scoring system agents use to choose the best action
